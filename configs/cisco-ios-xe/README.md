# Configurações Cisco IOS/IOS XE

Este diretório pode conter configurações adaptadas a uma versão específica do IOS/IOS XE. Os exemplos dos módulos são fragmentos didáticos, não configurações completas prontas para produção.

Antes de aplicar:
1. confira a versão e o suporte à sintaxe;
2. substitua todos os endereços e ASNs;
3. confirme prefixos de origem e políticas de exportação;
4. revise `maximum-prefix`;
5. valide rotas anunciadas por vizinho;
6. tenha rollback.
