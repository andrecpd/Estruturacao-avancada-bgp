# Exercícios e avaliações

Para cada módulo, responda aos exercícios no final do arquivo correspondente. Entregue comandos, saídas relevantes e justificativa, não apenas a configuração final. O avaliador deve observar se o aluno entende a diferença entre sessão, recepção de rotas, seleção de melhor caminho, instalação na RIB/FIB e anúncio ao peer.
